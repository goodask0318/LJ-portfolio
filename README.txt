이준 웹 포트폴리오 — HTML / CSS / JavaScript

실행 방법
압축을 풀고 index.html을 Chrome 또는 Edge에서 여세요.
인터넷에 연결되어 있으면 Google Fonts를 사용합니다. 연결되지 않아도 기본 글꼴로 표시됩니다.

파일 구성
index.html: 자기소개, 작업물, 이력, 연락처의 HTML 구조
style.css: 색상, 레이아웃, 모바일 반응형, 배경 애니메이션
app.js: 작품 데이터, 분야 필터, 작품 상세 창, 강아지 영상 선택, 움직임 설정
assets/: 강아지 사진·영상, 작품 미리보기, 팀프로젝트 PDF

수정 방법
연락처와 소개 문구: index.html
새 프로젝트 추가: app.js 맨 위 projects 배열에 항목 추가 후 assets에 이미지 저장
완료 여부: 프로젝트 status를 완료 또는 제작 중으로 설정
디자인: style.css의 :root 색상과 각 영역 스타일 수정
